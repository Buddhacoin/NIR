# NIR Wallet для Firefox — локальная тестовая сборка

Это расширение браузера без Mac-приложения и без восьмизначного кода. Оно создаёт
24-словную фразу, шифрует её паролем в локальном хранилище расширения, позволяет
восстановить те же NIR-адреса на другом устройстве, добавлять адреса и повторно
посмотреть фразу в настройках после ввода пароля.
На новом устройстве восстановление показывает первые 16 адресов этой фразы:
число ранее открытых адресов не записано в самих 24 словах.
Открытая вкладка блокируется после пяти минут бездействия либо при потере фокуса;
незавершённое создание или восстановление при этом начинается заново. Записанная
зашифрованная фраза не удаляется.
Переключатель RU/EN в верхней части окна меняет язык интерфейса без изменения
фразы или зашифрованного профиля. Выбор языка хранится отдельно на этом
устройстве; 24 слова восстановления остаются английскими в обоих режимах.

**Это не публичный релиз и не кошелёк для реальных средств.** Подключение к
публичной сети, баланс, отправка NIR, майнинг, dapp-подключение и автоматическая
синхронизация между устройствами ещё не реализованы. В браузере остаётся только
зашифрованная фраза; для восстановления на другом устройстве её нужно ввести
вручную и задать новый локальный пароль. Если устройство украдут, стойкость
защиты зависит от вашего пароля и безопасности самого устройства.

## Установка для обычных пользователей

Пока **недоступна**: расширение ещё не подписано Mozilla и не опубликовано в
Firefox Add-ons. После публикации здесь будет прямая ссылка «Добавить в Firefox»;
пользователю не понадобятся ZIP, папки, Node.js или аккаунт разработчика.
Обновления опубликованного расширения будет доставлять Firefox. Не скачивайте
«NIR Wallet» с посторонних сайтов: сейчас официальной страницы установки нет.

## Подготовка публикации для владельца проекта

`npm ci && npm run package:firefox` создаёт в `artifacts/firefox/` ZIP для
загрузки в Mozilla Add-on Developer Hub. Он **не подписан** и не устанавливается
обычным способом. Проверка `npx web-ext lint --source-dir dist-firefox` должна
проходить без ошибок; перед отправкой нужны проверка безопасности и исходный
код для рецензентов Mozilla. Точные, не обещающие действующую сеть сведения для
страницы магазина — в [`FIREFOX-LISTING.md`](FIREFOX-LISTING.md). Издатель входит
в свой аккаунт на [addons.mozilla.org/developers](https://addons.mozilla.org/developers/)
и загружает пакет сам; учётные данные нам не нужны.

Пакетирование из репозитория отказывается работать с незакоммиченными изменениями
исходников кошелька. Команда также создаёт архив исходников для Mozilla и JSON
с Git-ревизией, идентификатором расширения и SHA-256 обоих архивов и каждого
файла внутри ZIP. `npm run test:release` дважды собирает пакет и сверяет байты.
Перед загрузкой издатель сверяет эти хеши с проверенным GitHub Actions артефактом;
после подписи отдельно проверяется полученный от Mozilla XPI. JSON не является
цифровой подписью Mozilla и сам по себе не разрешает установку одним кликом.

## Локальная установка для разработки

1. Установите Node.js 26 или новее и в этой папке выполните `npm ci`, затем
   `npm run build`.
2. В Chrome откройте `chrome://extensions` (в Edge — `edge://extensions`),
   включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
3. Выберите папку `browser-wallet/dist`. Значок NIR появится в панели браузера.
   При первой установке откроется экран создания или восстановления; позже
   нажимайте значок NIR в панели браузера, чтобы открыть кошелёк.

Для технических тестировщиков успешная проверка GitHub Actions также сохраняет
архив `nir-browser-wallet-developer-preview` на семь дней. Его нужно распаковать
и выбрать распакованную папку на шаге 3. Это не установка из магазина и не
автоматическое обновление; обычным пользователям пока не рекомендуем этот путь.

Для Firefox 142+ команда `npm run build:firefox` создаёт `dist-firefox`, а
`npx web-ext lint --source-dir dist-firefox` проверяет пакет. Её можно временно
загрузить через `about:debugging`, но обычная установка Firefox требует подписи
Mozilla. Не устанавливайте Chromium ZIP в Firefox.
Safari требует отдельного подписанного приложения/расширения Apple; сборка
Firefox или Chromium не является установщиком Safari или iPhone. Edge и другие
настольные браузеры на Chromium потенциально совместимы с Chromium-сборкой,
но пока отдельно не проверены.

Не вводите в эту тестовую сборку фразы от других кошельков или адресов с
ценностью. Не публикуйте фразу, пароль, содержимое хранилища расширения или
снимки экрана с фразой. Удаление расширения может удалить зашифрованную копию;
сохранённая офлайн фраза — единственный способ восстановить адреса.

## Проверки

`npm test` сравнивает вывод адресов с нативным NIR ML-DSA-65 и проверяет
шифрование/отказ неверного пароля и логику тайм-аута. Firefox E2E проверяет
очистку фразы при событии потери фокуса во вкладке; поведение настоящего popup
отдельно ещё не проверено. `npm run test:browser` устанавливает
расширение в отдельный временный Chromium-профиль и проходит создание, добавление
адреса, блокировку, разблокировку и восстановление по фразе. Этот тест требует
браузер Playwright (`npx playwright install chromium`). Личный профиль Chrome
не используется.
Он также проверяет переключение RU/EN во время сохранения фразы, перевод ошибок,
сохранение языка после перезагрузки и восстановление в английском интерфейсе.

Код не запрашивает доступ к сайтам и не внедряет скрипты в страницы. Для
публикации в магазинах расширений нужны отдельная проверка безопасности,
полноценный сетевой кошелёк, подготовка страницы магазина и учётная запись
издателя. До публикации не называйте эту сборку официальным релизом.
