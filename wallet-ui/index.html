          Адрес для Model Lab

          Вставьте одноразовый запрос из локального Model Lab. Кошелёк попросит отдельное подтверждение и пароль. Подпись подтверждает только владение адресом: она не переводит средства и не даёт награды. Скопированное доказательство содержит публичный адрес и доступно другим приложениям через буфер обмена.

          Подтверждение хэша Iris адресом

          Вставьте intent из Model Lab после запуска Iris. Сверьте адрес, nonce и digest в системном запросе подписи. Подпись не доказывает выполнение модели; это не заявка в сеть и не награда.

          Пароль вводится только в окне macOS. Старые резервные копии и коды продолжают открывать тот же адрес.

            Создание и восстановление

            Команды выполняются в терминале из проверенной установки NIR. Пароль вводится скрыто и не попадает в историю команд.

            1. Новый файл кошелькаnpm run wallet:create -- /безопасный/путь/personal.nirvault.json
            2. Проверенная копияnpm run wallet:backup -- personal.nirvault.json /другой/диск/backup.nirvault.json
            3. Проверка копииnpm run wallet:verify -- /другой/диск/backup.nirvault.json
            4. Восстановлениеnpm run wallet:restore -- backup.nirvault.json /новый/путь/personal.nirvault.json

            Не храните пароль рядом с файлом кошелька. Сделайте минимум две проверенные офлайн-копии в разных местах.
