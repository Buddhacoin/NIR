# Первый прогон обучаемой модели через NIR

Этот пример проверяет настоящий вычисляемый вывод модели, а не JSON с заранее
записанными ответами. Он остаётся **локальной исследовательской репетицией**:
публичной сети, вознаграждения, скрытого набора заданий и безопасной песочницы
здесь нет. Это не LLM и не доказательство нового навыка общего ИИ.

## Что сравниваем

- Данные: [Iris из UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/53/iris),
  150 наблюдений и четыре числовых признака. Источник — R. A. Fisher, лицензия
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Локальная копия
  `examples/iris.data` отличается от исходного файла только удалёнными пустыми
  строками в конце; её SHA-256 —
  `596ffd580471ca4d4880f8e439c7281f3b50d8249a5960353cb200b1490f63a0`.
- Разделение: каждая пятая строка отложена для проверки (30 примеров), остальные
  120 используются как обучающие. Разделение фиксировано до запуска.
- Исходная модель: центры трёх классов, вычисленные по двум признакам чашелистика.
- Кандидат: 3 ближайших соседа по всем четырём признакам. Ответ выводится из
  обучающих строк при запросе; ID задания не определяет ответ.
- NIR запускает каждый вариант через экспериментальный `ApplicationAdapter`
  три раза, формирует transcripts, строит bundle и повторно его проверяет.

Из корня репозитория с Python 3.11+:

```bash
python3 -m nir.iris_rehearsal
python3 -m unittest tests.test_iris_real_model -v
```

Первая команда — используемый локальным приложением исполняемый сценарий, а
не тестовый метод. Она сверяет SHA-256 встроенного адаптера и набора данных до
запуска, выполняет их из приватных копий, проверяет сериализованный bundle и
выводит JSON со счётом обеих моделей. Из браузера нельзя передать свой код или
путь. Это не аттестация остальных Python-модулей, интерпретатора или всей копии
репозитория — запускать следует только доверенный исходный код. Указанные в
манифесте CPU, memory и timeout описывают ожидаемую среду, но локальный
`ApplicationAdapter` не обеспечивает её изоляцию или лимиты. На macOS после
установки Node.js 26+ и Python 3.11+ тот же сценарий
доступен через `npm run mine:app`. Это по-прежнему **не** отправка в сеть.

Ожидаемый результат в зафиксированном наборе: исходная модель — 27/30 (90%),
кандидат — 29/30 (96,66%). Тест также подаёт два разных набора признаков с
одним и тем же ID задания и требует разных предсказаний. Не нужны скачивание
модели, облачный API, пароль кошелька или GPU.

## Передача локального свидетельства другому оператору

После проверки Iris в Model Lab можно скачать JSON локального свидетельства.
Эквивалентный вывод из доверенной копии исходников:

```bash
python3 -B -m nir.iris_rehearsal --export-evidence
```

На *другом* компьютере оператор может открыть проверенную копию Model Lab,
выбрать JSON в разделе «Повторить проверку Iris» и нажать «Повторить проверку
локально». Приложение ограничивает файл 1 МБ и через отдельный локальный сервис
снова запускает встроенный пример; оно не получает код или путь исполнения из
файла. Эквивалентная команда из той же проверенной версии исходников:

```bash
python3 -B -m nir.iris_rehearsal --verify-evidence < evidence.json
```

Проверяющая команда принимает не более 1 МБ, не берёт из JSON путь или команду,
повторно запускает только закреплённый локальный пример и требует совпадения
всего свидетельства. Вывод `local-iris-evidence-matched` сообщает лишь о
совпадении двух локальных прогонов; он **не** удостоверяет личность оператора,
независимость машин, безопасность модели, адрес кошелька, сетевую заявку или
право на награду. JSON содержит публичный пример и не должен содержать ключей.

## Свой файл модели: только данные, без исполняемого кода

В Model Lab можно скачать `iris_integer_linear.json`, изменить целочисленные
`weights` (матрица 3×4) и `bias` (три числа), затем выбрать файл в разделе
«Проверить свой файл модели Iris». Классы закреплены в порядке
`Iris-setosa`, `Iris-versicolor`, `Iris-virginica`; четыре признака выражены в
десятых долях исходных измерений. Решение — класс с наибольшим целочисленным
значением `bias + weights × features`, при равенстве первый класс. Принимается
только канонический JSON с ключами `bias`, `format`, `weights`, не более 4 КБ;
дополнительные поля, код, ссылки на файлы, дробные и чрезмерные числа
отклоняются. Хеш с разделением домена привязывает результат к точным весам.

Это **не** универсальная загрузка AI-модели, безопасная песочница или заявка
на награду. Данные и все 30 проверочных ответов Iris публичны, поэтому даже
100 % точность файла-примера не доказывает новый навык, независимую оценку или
право на NIR. Тот же файл можно проверить на другом Mac, но личность и
независимость оператора по совпадению локальных результатов не установлены.
Приложение не запускает предоставленный участником Python, shell или ONNX.

## Что это пока не доказывает

Набор данных и правильные ответы опубликованы. Процесс адаптера не изолирован
от файловой системы: злонамеренный кандидат мог бы прочитать ответы, несмотря
на то, что честная реализация использует только обучающие строки. Разделение
на три запуска не означает независимых операторов или разных компьютеров.
Хеш измеренного entrypoint не является аттестацией всей среды выполнения.
Измерение энергии не подтверждено (`energy_attested=false`). Данные, политика
оценки и модель подобраны для небольшого учебного примера, а не для выявления
мирового прогресса. Никакой адрес кошелька не кредитуется.

Следующий этап: изолированное выполнение на разных машинах с действительно
скрытым после commitment набором заданий, измеренными моделью и зависимостями,
подписанными свидетельствами, проверкой энергии и повторением на независимых
операторах. Лишь после этого можно обсуждать публичные тестовые награды.
