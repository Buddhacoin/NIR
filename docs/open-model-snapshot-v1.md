# Local model-package snapshot preflight

This is a narrow preparation step for open-model testing, not an AI miner. It copies a selected core-file package for one curated model into a private temporary directory, checks every byte against its manifest, and removes the copy when the caller exits the snapshot context. The original model directory can then change without silently changing the bytes in that particular copy. A full downloaded repository, including its README and Git metadata, is not accepted unchanged.

For Qwen3-0.6B the package must include `config.json`, `generation_config.json`, `model.safetensors`, `tokenizer.json`, `tokenizer_config.json`, `merges.txt`, `vocab.json`, and `LICENSE`. The TinyLlama profile has its own required file set. Every supplied file must be in the manifest; missing, extra, linked, or changed files are rejected. Only fixed repository names and full revision hashes are accepted. Model weights are **not** bundled or downloaded by this code.

The local copy and its manifest are not proof of publisher authorship. A separate Hub consistency check compares files with metadata at a pinned revision, but that service and its TLS connection remain trust assumptions. Neither check signs or locks the snapshot. Another process with the same user privileges can change permissions and replace temporary files *after* this function returns; the reported identity then refers to the previously checked bytes, not necessarily the bytes a later path-based runner reads. This is a release-blocking gap for reward-bearing execution. The copy must not be treated as a security sandbox or an immutable consensus artifact.

There is no model runtime, deterministic cross-machine inference, independent assessor assignment, safety veto, consensus finalization, or NIR reward in this change. Before the package can enter that path, an isolated executor must consume exactly these checked bytes, enforce resource limits and a reviewed runtime, and produce independently reproducible evidence. No reward may be issued from this preflight alone.
